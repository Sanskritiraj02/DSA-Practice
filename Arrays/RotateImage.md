# Rotate Image

🔗 **Problem Link:** https://leetcode.com/problems/rotate-image/

---

## 🧠 Approach
- Transpose the matrix  
- Reverse each row  

---

## ⚡ Complexity
- **Time:** O(n²)  
- **Space:** O(1)  

---

## 💡 Key Insight
A 90° rotation can be achieved by transposing the matrix
and then reversing each row.
