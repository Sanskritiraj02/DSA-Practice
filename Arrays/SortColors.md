# Sort Colors

🔗 **Problem Link:** https://leetcode.com/problems/sort-colors/

---

## 🧠 Approach
- Use three pointers: low, mid, high  
- Place 0s at beginning and 2s at end  
- Traverse once using mid pointer  

---

## ⚡ Complexity
- **Time:** O(n)  
- **Space:** O(1)  

---

## 💡 Key Insight
By partitioning the array into three regions, we can sort it
in one pass without using extra space.
