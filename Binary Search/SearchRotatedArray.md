# Search in Rotated Sorted Array

🔗 https://leetcode.com/problems/search-in-rotated-sorted-array/

---

## 🧠 Approach
- Use binary search
- Identify which half is sorted
- Narrow search space accordingly

---

## ⚡ Complexity
- Time: O(log n)
- Space: O(1)

---

## 💡 Key Insight
At least one half of the array is always sorted,
even after rotation.
