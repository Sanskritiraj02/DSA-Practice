# Koko Eating Bananas

🔗 https://leetcode.com/problems/koko-eating-bananas/

---

## 🧠 Approach
- Binary search on answer (k)
- Use helper function to validate
- Minimize k

---

## ⚡ Complexity
- Time: O(n log max(pile))
- Space: O(1)

---

## 💡 Key Insight
Transform optimization problem into a YES/NO problem.
