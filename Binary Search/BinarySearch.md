# Binary Search

🔗 **Problem Link:** https://leetcode.com/problems/binary-search/

---

## 🧠 Approach
- Use two pointers: left and right  
- Find mid element  
- Reduce search space based on comparison  

---

## ⚡ Complexity
- **Time:** O(log n)  
- **Space:** O(1)  

---

## 💡 Key Insight
Binary search works only on sorted arrays and reduces
the search space by half each time.
