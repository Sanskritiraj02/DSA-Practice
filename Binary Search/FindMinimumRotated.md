# Find Minimum in Rotated Sorted Array

🔗 https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/

---

## 🧠 Approach
- Use binary search
- Compare mid with right
- Eliminate sorted half

---

## ⚡ Complexity
- Time: O(log n)
- Space: O(1)

---

## 💡 Key Insight
Minimum element lies in the unsorted part of the array.
