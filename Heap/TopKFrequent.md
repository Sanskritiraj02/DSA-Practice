# Top K Frequent Elements

🔗 https://leetcode.com/problems/top-k-frequent-elements/

---

## 🧠 Approach
- Count frequency using hashmap
- Use min heap of size k
- Keep highest frequency elements

---

## ⚡ Complexity
- Time: O(n log k)
- Space: O(n)

---

## 💡 Key Insight
Use heap to efficiently track top k frequent elements.
